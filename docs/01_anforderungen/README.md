# Anforderungen

Geplanter Inhalt (-> `<hauptverantwortlich>_requirements.pdf`):

- `produktidee.md` – Problem, Zielgruppe, Wertversprechen
- `hypothesen.md` – zentrale Annahmen und wie sie validiert werden
- `interviewleitfaden.md` – Leitfaden für Kunden- und Expertengespräche
- `anforderungen.md` – User Stories (US-…) und nicht-funktionale Anforderungen (NFR-…)
- Vorgehen bei Erhebung und Validierung

Kennungen: `US-001` User Story, `NFR-001` nicht-funktionale Anforderung,
`FB-001` Feedback (siehe `docs/06_feedback/`). Jede Anforderung nennt Rationale,
Stakeholder und Quelle.
