# Testen und Qualitätssicherung

Geplanter Inhalt (-> `<hauptverantwortlich>_testing.pdf`):

- `teststrategie.md` – Testebenen (Unit, Komponente, Akzeptanz), Werkzeuge
- Testfälle mit Eingaben und Testorakel (`TC-…`)
- `review-leitfaden.md` – Review-/Inspektionsleitfaden
- Testergebnisse (bestanden/fehlgeschlagen); Defekte als Issues mit Label `typ: bug`

Automatisierte Tests liegen unter `tests/unit`, `tests/integration`, `tests/acceptance`.
